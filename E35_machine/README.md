# E35 无线串口上位机

双击“启动上位机.bat”，选择电脑端 E35 对应串口，115200 波特率，点击连接。
请配合协议 v1 的新固件使用。上位机自动接收 200 Hz 定点二进制控制遥测，
校验 CRC，解码成物理单位；界面只保留最新一条，约 30 Hz 刷新。

连接后自动在本目录 logs 文件夹生成完整日志：

- CSV：全部有效控制采样，包括采样时间、拍号、状态/错误、航向/误差、
  Z 角速度、左右速度、转向指令、舵机指令偏移、PWM、位置、路径进度和速度目标。
- JSONL：命令、回执、标定进度、诊断统计、数据中断和恢复事件。
- BIN：串口原始字节，用于后续重放和排查坏帧。

界面显示日志实际路径；清空界面不会删除日志。正常点击断开或关闭窗口会刷盘。
若目录不可写或磁盘已满，界面会提示日志写入失败。

上电首先广播数据，点击“IMU 零偏标定”后静止约 10 秒，ARMED 后可 START。
STOP 停车。DEBUG 保留按钮和键盘双支持；按住上键加速，按住下键减速，
左右键转向，松开转向回中。遥控需持续心跳，失联会停车。

若烧录的是 DEMO_component 的模块1，保持默认“发车模式：模块1：按PWM/时间”，
选择整数PWM 10–40%和保持时间2–5秒，再点击唯一的“发车 START”。上位机一次发送
`CONFIG,25,5`，小车校验并回传 `CONFIG,OK,25,5`；上位机核对一致后才发 `START`。
无回传、参数不一致或超时均不发车；仅当小车处于ARMED时固件才接受参数。
到时电机PWM直接归零，舵机用IMU和编码器反馈修正直线。模块4请选择“模块4：按航向角/速度”，
设置目标航向变化角、舵机偏角幅值及转弯/回正后速度；小车回传C4参数确认后才发START。
运行模块2、3、5或旧固件时选“其他模块：普通START”。改上位机代码后请重启此程序；改固件
代码后须重编译、烧录。

超过 500 ms 没有有效控制帧，界面标记数据过期；恢复后新建日志时间段。
采样时间由 5 ms 控制拍号展开，自动处理 65535 → 0 回绕。

协议字段、量化精度、标志位、带宽和时间处理见 [PROTOCOL.md](PROTOCOL.md)。

离线检查：

```powershell
.venv\Scripts\python.exe -m py_compile main.py protocol.py
.venv\Scripts\python.exe verify_protocol.py
```

目前未接 MCU；200 Hz 是固件发送目标，实际无线吞吐需实机确认。
